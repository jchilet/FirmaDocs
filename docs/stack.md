# Stack — FirmaDocs
- Framework: .NET 10.
- Lenguaje: C# 14.
- Pruebas: xUnit.
- Sustitución de dependencias: NSubstitute.
- Tipo de aplicación: consola.
- Compilar: dotnet build.
- Ejecutar pruebas: dotnet test.
- Los nombres de los tests deben incluir el identificador del requisito funcional (RF).
